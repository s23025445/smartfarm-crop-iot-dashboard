# SmartFarm frontend

This folder contains the React and Vite frontend for the SmartFarm Crop Dashboard.

Start the Express backend first. Then run:

```bash
npm install
npm run dev
```

The dashboard opens at `http://localhost:5173` and calls the API at `http://localhost:3000/api`.

Useful checks:

```bash
npm test
npm run lint
npm run build
```
